# Brief ảnh cho agy (Gemini)

Thả file vào `fe/public/fx/`. Ảnh PNG nền trong suốt, vuông 512x512, không chữ.

| File | Dùng khi | Prompt gợi ý |
|---|---|---|
| `capture-burst.png` | Ăn quân (hiện ở ô bị ăn, phóng to rồi mờ) | "Game VFX sprite, ink-brush splash and golden sparks burst, top-down, centered, Chinese ink style, transparent background, no text" |

Hiện chỉ `capture-burst.png` được nối vào code; nếu thiếu file thì giữ hiệu ứng vẽ bằng SVG.
Ảnh khác (bàn cờ gỗ, mặt quân cờ, nền chiến thắng) có thể gen thêm rồi báo để nối vào.
